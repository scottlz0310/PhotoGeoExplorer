# 手動テストチェックリスト

日常の品質確認は手動テストを重視します。E2E は UIA(FlaUI) で実アプリを起動するため
環境依存の不安定さがあり、通常はスキップします。

## 実行前

- `dotnet build PhotoGeoExplorer.sln -c Release -p:Platform=x64`
- `dotnet run --project PhotoGeoExplorer/PhotoGeoExplorer.csproj -c Release -p:Platform=x64`

## 基本動作

- アプリが起動し、クラッシュしない
- フォルダ選択ができ、一覧に画像が表示される
- 画像プレビューが表示できる
- 地図が表示され、ピンが表示される

## フォルダー選択の履歴（#235・#262）

実写真を使わず、検証用の JPEG 複数枚と移動・コピー先フォルダーを用意する。
移動・コピー・開くの各経路で、以下を確認する。

- 同じフォルダー A を2回以上続けて選択し、決定ボタンが有効なまま確定できる
- 移動は別の検証用ファイルを同じ A に移せ、コピーは元ファイルを保持して A に複製できる
- 開くは同じ A を続けて指定でき、一覧が更新される
- キャンセルでファイル操作やフォルダー遷移が行われない
- 開く・移動・コピーのそれぞれで、前回確定したフォルダーからダイアログが開く（3 経路の履歴が混ざらない）
- 前回確定したフォルダーが無い（初回、または削除・改名した）ときは、いま表示しているフォルダー（存在しなければ存在する最も近い親フォルダー）からダイアログが開く
- 前回確定したフォルダーが開いた状態で、何も変えずに決定ボタンを押して確定できる
- アプリを終了して再起動した後は、前回確定したフォルダーではなく、いま表示しているフォルダーからダイアログが開く（記憶はアプリ実行中だけ）
- キャンセルでは前回確定したフォルダーが更新されない
- Windows App SDK の FolderPicker は `SettingsIdentifier` を指定しても前回フォルダーを復元しないため、アプリ側で記憶している（非パッケージ起動・MSIX とも）

## 地図画像の保存ダイアログの履歴（#265）

GPS 付きの検証用 JPEG を表示した状態で、地図ペインの保存ボタンから確認する。

- 初回（アプリ起動直後）は、いま表示しているフォルダーから保存ダイアログが開く
- 別のフォルダー B に保存した後、もう一度保存ボタンを押すと、B からダイアログが開く
- 保存ダイアログをキャンセルしても、前回保存したフォルダー B は変わらない
- B を削除・改名した後は、いま表示しているフォルダーから開く
- アプリを終了して再起動した後は、B ではなく、いま表示しているフォルダーから開く（記憶はアプリ実行中だけ）
- Windows App SDK の保存ダイアログは `SettingsIdentifier` を指定しても前回の保存先を復元しないため、アプリ側で記憶している

## Mapbox 航空写真（#291）

実トークンでの確認は、自分の Mapbox アカウントで発行した公開トークン（`pk.`）を使う。

- トークン未設定のとき、設定の「Mapbox Satellite」は選べない（無効表示）
- `sk.` で始まるトークンは保存できず、理由が表示される
- 公開トークンを保存すると「トークン: 設定済み」になり、「Mapbox Satellite」を選べる
- 「接続テスト」が、有効なトークンで成功、無効なトークンで「トークンが無効、または権限がありません」になる
- Mapbox Satellite に切り替えると航空写真が表示され、写真ピンの位置が OpenStreetMap / Esri のときと一致する
- 地図の右下の帰属表示が、背景ごとに切り替わる（OpenStreetMap / Esri / Mapbox）
- Mapbox Satellite の帰属表示は 3 つのリンクに分かれ、`© Mapbox` は Mapbox、`© OpenStreetMap` は OpenStreetMap の著作権ページ、`Improve this map` は表示中の位置の修正依頼ページを、それぞれブラウザーで開く
- Mapbox Satellite を表示している間だけ、地図の左下に Mapbox のロゴが表示される
- 地図画像を保存すると、PNG の右下にも同じ帰属表示が入る（Mapbox Satellite のときは左下のロゴも入る）
- Mapbox Satellite を選んだままトークンを「削除」すると、OpenStreetMap の表示になり、地図の左上に注意書きが出る。設定の選択は Mapbox Satellite のまま
- 無効なトークン（形式は正しいが失効済みなど）で Mapbox Satellite を表示すると、地図の左上に「トークンが無効、または権限がありません」と出る
- `%LocalAppData%\PhotoGeoExplorer\settings.json` と、設定のエクスポート結果にトークンが含まれない
- `%LocalAppData%\PhotoGeoExplorer\Logs\app.log` にトークンが含まれない（`access_token=***` になる）
- `%LocalAppData%\PhotoGeoExplorer\Cache\Tiles` に `MapboxSatellite` フォルダーが作られない
- アプリを再起動しても、トークンと Mapbox Satellite の選択が保持される

## 地図ヘッダーの撮影位置情報（#292）

字地名と最寄り道路名は、判定の実装（#294・#296）が入るまで表示されない。この節では緯度・経度と表示の枠組みを確認する。

- GPS つきの写真を 1 枚選ぶと、地図ヘッダーの「地図」の右に緯度・経度が小数 6 桁で表示される（例: `43.468212, 142.482015`）
- 緯度・経度をクリックするとクリップボードへコピーされ、通知バーにコピーした値が出る
- 未選択・複数選択・GPS なしの写真・フォルダーの選択では、緯度・経度が表示されない（前の写真の値が残らない）
- 地図ペインの幅を縮めると緯度・経度が消え、「地図画像を保存」ボタンは隠れない。幅を戻すと再び表示される
- 地図ヘッダーを右クリックすると 4 項目のメニューが開き、現在の設定どおりにチェックが付いている
- 右クリックメニューで「緯度・経度を表示」を切り替えると、ヘッダーの表示と設定画面のチェックボックスの両方に反映される（逆方向も同じ）
- 切り替えた設定が、アプリの再起動後も保持される
- 設定の「リセット」で、4 項目が既定（住所・道路名・緯度経度がオン、都道府県名がオフ）に戻る
- 日本語・英語のどちらでも、メニューと設定画面の文言が表示される

## 地域データ（字地名）の取り込み（#294）

設定画面での取り込み・一覧・削除を確認する。ヘッダーへの表示は次の「地図ヘッダーの字地名」で確認する。e-Stat の「統計地理情報システム」→「境界データダウンロード」→「小地域」→「国勢調査」→「小地域（町丁・字等別）」→「世界測地系緯度経度・Shapefile」で、都道府県ごとの ZIP を取得しておく（例: `r2ka31.zip` = 令和 2 年・鳥取県）。

- 設定画面に「地域データ（字地名）」の節があり、最初は「取り込み済みの地域データはありません。」と出る
- 「ZIP を追加...」でファイル選択が開き、e-Stat の ZIP を選ぶと「鳥取県（2020年）の地域データを取り込みました。」と出て、一覧に「鳥取県　2020年・4.7 MB」と「削除」が並ぶ
- `%LocalAppData%\PhotoGeoExplorer\AreaData\31\` に `r2ka31.shp`・`.shx`・`.dbf`・`.prj` の 4 つだけが置かれる
- 設定画面を閉じて開き直しても、一覧が残っている。アプリを再起動しても残っている
- 同じ都道府県の ZIP をもう一度取り込むと、一覧は 1 行のまま（置き換わる）
- ZIP ではないファイル、`.shp` などがそろっていない ZIP、複数の都道府県が混ざったデータ、座標系が平面直角座標系のデータを選ぶと、理由が表示され、既存の一覧とデータは変わらない
- ファイル名から調査年を判別できない ZIP（`.shp` の名前が `r2ka31` の形でない）は、その旨が表示される
- 取り込み中は「ZIP を追加...」と「削除」が押せない
- 「削除」を押すと「鳥取県の地域データを削除しました。」と出て、一覧から消え、`AreaData\31` フォルダーもなくなる。削除ボタンの読み上げ名は、行ごとに「鳥取県の地域データを削除」になる
- 節に出典（政府統計の総合窓口(e-Stat)・加工して作成・国・総務省が作成したものではない）と、ダウンロードページへのリンクが表示され、リンクがブラウザーで開く
- 日本語・英語のどちらでも、節の文言・メッセージが表示される
- 北海道の ZIP（展開後約 32MB）を取り込んで、画面が固まらず数秒で終わる

## 地図ヘッダーの字地名（#294）

e-Stat の鳥取県の ZIP（例: `r2ka31.zip`）と、鳥取県内で撮影した GPS つきの写真（鳥取県外の写真、水面で撮った写真があるとなおよい）を用意する。

- 地域データを取り込む前: 鳥取県の写真を 1 枚選ぶと、住所は出ず、緯度・経度だけが出る
- 設定画面で ZIP を取り込むと、**写真を選び直さなくても**、地図ヘッダーに「鳥取市 ○○」のような住所が出る
- 住所にポインターを合わせると、「鳥取県 鳥取市 ○○」（都道府県名つき）・「小地域コード: ……（2020 年 国勢調査）」が出る。設定の「住所表記に都道府県名を含める」を切り替えても、ツールチップは都道府県名つきのまま
- 道路や海岸の端で、境界の外になる地点の写真では、ツールチップに「30 m 以内の最寄りの小地域に補正しています」と出る
- 海（日本海）の上で撮った写真では、住所は出ない
- 鳥取県外の写真・海外の写真では、住所は出ない（エラーも出ない）
- 設定画面で鳥取県のデータを削除すると、**写真を選び直さなくても**、住所が消える
- 同じ ZIP を取り込み直すと、住所が再び出る
- 複数の写真を選ぶ・何も選ばないと、住所と緯度・経度が消える
- 住所の表示をオフにすると住所だけが消え、オンに戻すと再び出る
- 幅を狭めると、緯度・経度 → 道路名 → 住所の順に省略される（住所は末尾が「…」になる）
- 日本語・英語のどちらでも、ツールチップの文言が表示される
- ヘルプ（日本語・英語）に「地域データ（字地名）の取り込み」の手順と出典がある。プライバシーポリシーに地域データの項目がある

## 字地名のペイン（#298）

設定の「レイアウト」で、いずれかの領域のビューを「字地名」にして確認する。鳥取県の ZIP（`r2ka31.zip`）を取り込んでおき、鳥取県内・海上・県外・GPS なしの写真が混ざったフォルダー（数十枚）を開く。

- 設定の「レイアウト」の 3 つの選択肢のどれにも「字地名」がある。既定のレイアウト（ファイル・プレビュー・地図）では、字地名のペインは出ない
- 「字地名」を領域に割り当てると、その領域に字地名のペインが出る。それまで出ていたビュー（プレビューなど）は、どの領域にも出なくなる
- すでに別の領域に出ているビューを選ぶと、2 つの領域のビューが入れ替わる（例: 地図の領域に「字地名」を選び、字地名が出ていた領域は地図になる）
- 地域データを取り込む前は、「地域データなし (N)」と「位置情報なし (N)」だけが出て、地域データの取り込みを案内する文が出る
- 地域データを取り込むと、**フォルダーを開き直さなくても**、ツリーに「鳥取市 (N)」「岩美町 (N)」などの市区町村が出て、展開すると町丁・字（枚数つき）が並ぶ。市区町村の枚数は、町丁・字の合計と一致する
- 判定中は進捗（「字地名を判定しています… N / M」）と「中止」が出る。「中止」を押すと止まり、そこまでの結果が残る
- 町丁・字のノードを選ぶと、ファイル一覧でその枚数の写真が選択され（ステータスバーに「N 件を選択中」）、地図の領域にその数のピンが出る。市区町村のノードを選ぶと、その市区町村の全写真が選択される
- 展開したノードは、フォルダー内の写真が変わってツリーが作り直されても、開いたまま
- 別のフォルダーを開くと、ツリーがそのフォルダーの写真のものに変わる。GPS のない写真が「位置情報なし」に入る
- 設定画面で地域データを削除すると、ツリーが「地域データなし」に変わる
- 字地名のペインが表示されていない間（別のビューに切り替えているとき）は、判定が走らない（大きなフォルダーを開いても、ペインを出すまで重くならない）
- プレビューを最大化している間は、判定が走らない。元に戻すと、続けて判定される
- 日本語・英語のどちらでも、ペインの文言とノード名が表示される
- 数千枚のフォルダーで、画面が固まらず、進捗が進み、「中止」で止められる
- ヘルプ（日本語・英語）に「字地名で見る」の節がある
## 地理情報つきエクスポート（#299）

鳥取県の ZIP（`r2ka31.zip`）を取り込んでおき、鳥取県内・海上・県外・GPS なしの写真が混ざったフォルダー（数十枚）を開く。写真を選んでから行う（Ctrl+A で全選択）。

- 写真を何も選んでいないとき、「ファイル > エクスポート」の 3 項目は押せない。写真を選ぶと押せる。ファイル一覧の右クリックメニューにも「エクスポート」があり、同じ 3 項目が出る
- 位置情報つきの一覧（CSV）: 保存先を選ぶと、「N 枚の写真の情報を「xxx.csv」に書き出しました。」と出る。Excel でそのまま開いて、文字化けしない。列は「ファイル名・都道府県・市区町村・町丁字・キーコード・緯度・経度・撮影日時・判定」。字地名がない写真は住所の列が空で、判定が「地域データなし」「位置情報なし」「水面」になる。同じ保存先を選ぶと、保存ダイアログが上書きを確認する
- 字地名別のフォルダーへコピー: 出力先の下に「市区町村 / 町丁・字」のフォルダーができ、写真が入る。字地名がない写真は、「水面（住所なし）」「地域データなし」「位置情報なし」のフォルダーに入る。元の写真は、元のフォルダーに残っている。終わると「N 枚をコピーしました（スキップ M 枚）。」と出る
- 日付・字名の名前でコピー: 出力先に「20240102_字名_001.jpg」の形式でコピーされる（同じ日付・字名の写真は、撮影日時順に 001、002…）。出力先で名前が重ならない
- 同じ出力先へもう一度コピーすると、競合ダイアログ（すべて上書き・すべてスキップ・上書き・スキップ・中止）が出る。「すべてスキップ」→ 0 枚コピー・N 枚スキップ。「すべて上書き」→ N 枚コピー。「中止」→ そこで止まり、それまでの枚数が出る
- 書き出し中は、ステータスバーに「位置情報を読んでいます… N / M」「コピーしています… N / M」と「中止」が出て、終わると消える。「中止」を押すと、それまでの枚数つきで「中止しました」と出る（枚数が多い写真で確認する）
- 地域データを取り込んでいない状態で書き出すと、住所の列が空・「地域データなし」のフォルダーになる（エラーにならない）
- 日本語・英語のどちらでも、メニュー・進捗・通知・CSV の見出しが表示される（CSV の見出しは表示言語に合わせる）
- 数千枚で、画面が固まらず、進捗が進み、「中止」で止められる
- ヘルプ（日本語・英語）に「エクスポート」の節がある
## マルチモニター (異なるDPIスケーリング)
- 100%と150%など異なるスケーリングのモニター間でウィンドウを移動しても画像プレビューのサイズが一貫している
- DPI変更後もFitToWindowが正しく動作する
- 手動ズーム後にモニター移動しても視覚的サイズが維持される

## EXIF 編集

- JPEG 1 枚選択で「EXIF編集...」が有効
- 複数選択/フォルダ選択で EXIF 編集が無効またはエラーメッセージ
- 撮影日時のチェックをオフにすると日時UIと「更新日時同期」が無効
- 撮影日時のチェックをオンにすると日時UIと「更新日時同期」が有効
- 位置情報を入力して保存すると地図のピンが更新される
- 「地図から位置情報を取得」→地図クリックで緯度/経度が反映される
- 位置選択中に右クリックでキャンセルできる
- 位置選択中にドラッグで地図をパンできる
- 位置情報クリアで地図のピンが消える
- 撮影日時を更新しない場合に既存の日時が維持される
- 「更新日時同期」オンの場合、ファイル更新日時が撮影日時に一致する

## ペインレイアウト（#124）

- 設定 > レイアウトで、3 つのプリセット（左・中央・右 / 左・右上右下 / 左上左下・右）を切り替えられる
- 各領域のビュー割り当て（File / Preview / Map）を変更すると、メイン画面に即時反映される
- 同一ビューを複数領域に選択した場合、割り当てが重複しない（既存領域と入れ替わる）
- どのプリセット/割り当てでも、ファイル選択でプレビューと地図ピン連動が継続する
- アプリ再起動後に、プリセットとビュー割り当てが復元される
- プレビュー最大化の ON/OFF 後も、最大化解除時に選択済みレイアウトへ戻る

## 単一インスタンスとファイル関連付け（#215 / #240）

MSIX 版（`.\scripts\DevInstall.ps1` で導入）で、JPG の既定アプリを PhotoGeoExplorer にして確認する。
単一インスタンスのリダイレクトは MSIX のファイル activation 経由でのみ発生するため、`dotnet run` では再現できない。

- 起動済み・起動完了後にエクスプローラーで別の JPG をダブルクリックすると、既存ウィンドウが前面化し、対象フォルダーへ遷移して対象ファイルが選択される
- 起動直後（スプラッシュ表示中）に別の JPG をダブルクリックしても、クラッシュせず、最後に開いたファイルが最終的に選択される
- 短時間（約 100ms 間隔）に複数の JPG を連続して開いても、クラッシュせず、最後に開いたファイルが選択される
- 初回の JPG ダブルクリックによる起動で、対象フォルダーへの遷移とファイル選択が行われる
- イベントビューアー（Windows ログ > アプリケーション）に `PhotoGeoExplorer.exe` / `CoreMessagingXP.dll` の「アプリケーション エラー」（イベント ID 1000）が記録されない
- `app.log` にリダイレクトの経過（`Redirecting activation...` / `Activation redirect completed.` / `Redirected activation received` / `Startup file selected`）が残り、`ERROR` がない（`app.log` は起動時に削除されず過去のセッションも残るため、確認は今回の起動の `SessionId` の行に限る）

起動直後の連続起動を PowerShell で再現する例（`<フォルダー>` に JPG を置く）:

