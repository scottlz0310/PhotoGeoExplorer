PhotoGeoExplorer 詳細ヘルプ

写真の場所を地図で確認・整理するためのガイド

概要

PhotoGeoExplorer は写真の位置情報 (EXIF/GPS) を地図上に表示し、撮影場所を整理しやすくする Windows デスクトップアプリです。

  • 写真の一覧・プレビュー・地図表示を1つの画面で確認できます。
  • 地図上のピンから撮影日時やカメラ情報を確認できます。
  • 必要に応じて EXIF 情報の編集も行えます (JPEGのみ)。

対応環境と形式

動作環境

  • Windows 10/11
  • WebView2 Runtime (詳細ヘルプの表示に使用)

対応する画像形式

  • .jpg / .jpeg / .png / .gif / .bmp / .tif / .tiff / .heic / .webp

ファイル関連付け

  • .jpg / .jpeg / .png / .heic を既定アプリとして関連付け可能です。
  • 関連付けた画像を開くと、同じフォルダーが自動で読み込まれます。

初回起動

  • メニューの [ファイル] > [フォルダーを開く...] で写真のあるフォルダーを選びます。
  • フォルダーはドラッグ&ドロップでも開けます。
  • 写真を選ぶと右側にプレビューと地図が表示されます。
  • 位置情報がある写真のみ地図にピンが表示されます。
  • 前回開いていたフォルダーは起動時に復元されます (見つからない場合は近い親フォルダーにフォールバックします)。

画面の見方

  • 左 ファイルブラウザー: フォルダー移動、検索、一覧表示。
  • 右上 画像プレビュー: 写真の確認、ズーム、最大化。
  • 右下 地図: 位置情報の表示と操作。
  • 下部 ステータスバー: 件数/選択数/GPS情報の状態。
  • 任意 字地名: 現在のフォルダーの写真を、撮影地の字地名で束ねたツリー（初期状態では表示されません。「字地名」を参照）。

字地名で見る

  • 設定の「レイアウト」で、いずれかの領域の表示ビューを「字地名」にすると、現在のフォルダーの写真を、撮影地の「市区町村 > 町丁・字」で束ねたツリーを表示できます（同時に表示できるのは 3 つまでなので、プレビューや地図と入れ替えて使います）。
  • ノードを選ぶと、該当する写真がファイル一覧で選択され、地図とプレビューもその選択に合わせて更新されます。ファイルやフォルダーは移動・変更されません。
  • 「水面（住所なし）」は海や湖など住所のない場所、「地域データなし」は位置情報はあるが字地名を判定できない写真（地域データを取り込んでいない都道府県、日本国外など）、「位置情報なし」は GPS のない写真です。
  • 字地名の判定には、設定の「地域データ（字地名）」で都道府県のデータを取り込む必要があります（取り込み方法は「設定」を参照）。データを取り込む・削除すると、ツリーも自動で更新されます。
  • 写真の位置情報を読むため、枚数が多いと判定に時間がかかります。判定中は進捗が表示され、「中止」で止められます。字地名のペインが表示されていない間は、判定しません。
  • 対象は、ファイル一覧に表示されている現在のフォルダーの写真だけです（サブフォルダーは含みません）。

ナビゲーション

  • 戻る/進むボタンで、最近開いたフォルダー履歴を移動できます。
  • 「上へ」「ホーム」ボタンで素早く移動できます。
  • パンくずリストの区切り「>」をクリックすると子階層を開けます。

ファイル操作

  • 新しいフォルダーの作成、名前変更、移動、削除が行えます。
  • ドラッグ&ドロップでファイル/フォルダーを移動できます。
  • フォルダー移動はダブルクリックで行います。

検索・表示

  • 検索ボックスでファイル名の絞り込みができます。
  • [フィルター] や [表示] > [画像のみ表示] で対象を絞り込めます。
  • 表示モード (アイコン/リスト/詳細) は [表示] メニューから変更できます。
  • 詳細表示ではマウスオーバーで追加情報を確認できます。

プレビュー操作

  • プレビュー上部のボタンで拡大/縮小/フィット/最大化ができます。
  • 前後ナビゲーションで次の写真へ移動できます。
  • 最大化時は地図領域が自動的に再配置されます。

地図操作

  • ドラッグで移動、ホイールで拡大縮小できます。
  • ピンをクリックすると撮影日時/カメラ/ファイル名/解像度を確認できます。
  • ピンをクリックすると対応する写真が一覧で選択されます。
  • ピンの詳細から Google Maps で位置を開くことができます。
  • 地図タイルは OpenStreetMap / Esri WorldImagery（衛星画像）/ Mapbox Satellite（衛星画像）を切り替えできます。
  • OpenStreetMap と Esri の地図タイルはローカルキャッシュされ、再表示が高速化されます。Mapbox のタイルは端末に保存しません。
  • Mapbox Satellite を使うには、ご自身の Mapbox アカウントで発行した公開アクセストークン（pk. で始まるもの）が必要です。設定の「地図」で入力して「保存」すると選べるようになります。「接続テスト」でトークンが使えるか確認できます。
  • トークンは Windows の資格情報マネージャーに保存され、設定ファイルやエクスポートには含まれません。シークレットトークン（sk.）は保存できません。
  • Mapbox の利用量と料金は、トークンを発行したアカウントに計上されます。無料枠と料金は Mapbox の料金ページ（Raster Tiles API）でご確認ください。URL 制限つきのトークンはデスクトップアプリから使えないことがあります。
  • トークンを設定していない状態で Mapbox Satellite が選ばれている場合は OpenStreetMap を表示し、地図の左上にその旨を表示します。
  • 地図の右下に背景地図の提供元（帰属表示）を表示します。Mapbox Satellite の表示中は左下に Mapbox のロゴも表示します。保存した地図画像にも同じ表示が入ります。
  • 写真を 1 枚選ぶと、地図の見出しの右に撮影位置の住所（字地名）、最寄りの道路名（候補）、緯度・経度を表示します。緯度・経度をクリックするとコピーできます。表示する項目は、見出しの右クリックまたは設定の「地図」で切り替えできます。
  • 住所は、設定の「地域データ（字地名）」で該当する都道府県のデータを取り込むと表示されます（取り込み方法は「設定」を参照）。住所にポインターを合わせると、小地域コードと調査年を確認できます。撮影位置が小地域の境界の外にあるときは、30 m 以内の最寄りの小地域に補正して表示し、その旨も表示します。海や湖などの水面では住所を表示しません。
  • 最寄りの道路名（候補）は、撮影位置から 50 m 以内の道路を近い順に最大 3 件調べ、いちばん近い道路の名称を表示します（「(+1)」は、ほかの候補の件数）。道路名をクリックすると候補の一覧（名称・路線番号・距離）が開き、ポインターを合わせると距離を確認できます。最寄りの道路が撮影した対象の道路とは限らないため、確定値ではなく「候補」です。道路の種別（国道・都道府県道など）は推定せず、国道は名称（「国道53号」など）で、名称のない道路は「路線番号 203」のように表示します。駅のホームなど歩行者用の経路は含めません。
  • 道路名の候補の一覧の「確定」を押すと、その写真の道路名として確定できます（確定した写真は「✓ 道路名」と表示され、一覧の「確定を解除」で戻せます）。確定した内容は、写真のファイルには書かず、端末内の %LocalAppData%\PhotoGeoExplorer\road-name-confirmations.json に保存します（外部へは送信しません）。写真を移動・名前変更すると、確定は外れます。
  • 最寄りの道路名を調べるため、OpenFreeMap から道路のタイルを取得します。送信するのはタイルの番号（約 2 km 四方）だけで、写真や緯度・経度そのものは送りません。通信したくない場合は、設定の「地図」で「最寄り道路名（候補）を表示」をオフにしてください（詳しくはプライバシーポリシー）。取得したタイルは端末内にキャッシュされ、オフラインではキャッシュにあるタイルだけで調べます。

エクスポート（位置情報つきの書き出し）

  • ファイル一覧で写真を選び、「ファイル > エクスポート」またはファイル一覧の右クリックメニューの「エクスポート」から書き出せます。元の写真は変更されません。字地名のペインでノードを選ぶと、その場所の写真が選択されるので、そのまま書き出せます。
  • 位置情報つきの一覧（CSV）: ファイル名・都道府県・市区町村・町丁字・キーコード・緯度・経度・撮影日時・判定・道路名・道路名の区分を、CSV（UTF-8・BOM つき）で保存します。道路名の区分は「確定」（道路名の候補の一覧で確定した値）「候補」（未確定の写真の、最寄りの道路の第 1 候補）「なし」のいずれかです（既存の列の位置は変えず、末尾に足しています）。Excel でそのまま開けます。字地名がない写真は、住所の列を空にして、判定に「地域データなし」「位置情報なし」「水面」を入れます。
  • 字地名別のフォルダーへコピー: 出力先のフォルダーの下に「市区町村 > 町丁・字」のフォルダーを作り、写真をコピーします。字地名がない写真は、「水面（住所なし）」「地域データなし」「位置情報なし」のフォルダーへ入ります。
  • 日付・字名・道路名の名前でコピー: 出力先のフォルダーへ、「20240102_東品治町_山の手通り_001.jpg」のような名前（撮影日・字名・道路名・連番）でコピーします。道路名には、確定した道路名だけを入れ、未確定の写真は「道路名なし」になります（候補は、確定した値と見分けられないため、ファイル名には入れません）。
  • 道路名の候補は、設定の「最寄り道路名（候補）を表示」がオンのときだけ、書き出しの際に OpenFreeMap から道路のタイルを取得して求めます（地図ヘッダーと同じ設定・同じ通信です。オフにすると通信せず、確定した道路名だけを出力します）。通信できなかった写真の道路名は空になり、完了の通知にそのことが表示されます。
  • 出力先に同名のファイルがあるときは、上書き・スキップ・中止（と、すべて上書き・すべてスキップ）を選べます。
  • 書き出し中は、ステータスバーに進捗が表示され、「中止」で止められます。終わると、コピーした枚数・スキップした枚数・失敗した枚数が表示されます。
  • 字地名の判定には、設定の「地域データ（字地名）」で都道府県のデータを取り込む必要があります（取り込んでいない都道府県の写真は「地域データなし」になります）。

複数選択・矩形選択

  • Ctrl/Shift で複数選択できます。
  • 地図上で Ctrl を押しながらドラッグすると矩形選択ができます。
  • 矩形内の写真が一括選択され、左の一覧にも反映されます。

EXIF 編集

  • 写真を右クリックして [EXIF編集...] を選択します (JPEGのみ)。
  • 撮影日時/緯度/経度の編集ができます。
  • [地図から位置情報を取得] を選ぶと、地図クリックで位置を設定できます。
  • 位置選択中は右クリックでキャンセルできます。

設定

  • 言語/テーマの切り替えが可能です (変更後は再起動が必要です)。
  • 地図の初期倍率、タイルソースを変更できます。
  • 「レイアウト」で、各領域に表示するビュー（ファイル・プレビュー・地図・字地名）を選べます。
  • 設定のエクスポート/インポートに対応しています。
  • 「地域データ（字地名）」で、地図の見出しに表示する住所の判定に使うデータを取り込み・削除できます（下記）。

地域データ（字地名）の取り込み

  1. 政府統計の総合窓口（e-Stat）の境界データのダウンロードページで、「国勢調査」「小地域（町丁・字等別）」「2020 年」「世界測地系緯度経度・Shape 形式」を選び、取り込みたい都道府県の ZIP をダウンロードします。
  2. 設定の「地域データ（字地名）」で「ZIP を追加...」を選び、ダウンロードした ZIP を指定します。同じ都道府県のデータがあれば置き換えます。
  3. 不要になったデータは、一覧の「削除」で消せます。

取り込んだデータは端末の %LocalAppData%\PhotoGeoExplorer\AreaData に保存し、住所の判定も端末内で行います。本アプリはこのデータをダウンロードしません。

出典: 政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）「国勢調査 小地域（町丁・字等別）境界データ」（総務省統計局）を加工して作成。このデータは国・総務省が作成したものではありません。

ログ/更新/問い合わせ

ログの確認

  • ヘルプ > ログフォルダーを開く からログを確認できます。
  • ログの場所: %LocalAppData%\PhotoGeoExplorer\Logs\app.log

更新の確認

  • ヘルプ > アップデートを確認 から GitHub Release を確認します。

問い合わせ

  • 不具合報告は GitHub Issues を利用できます。
  • 再現手順とログを添えて連絡してください。

プライバシー

  • 写真や設定は端末内で処理され、外部に送信されません。
  • 地図タイルは OpenStreetMap / Esri のサーバーから取得します。Mapbox Satellite を選んだ場合は Mapbox のサーバーから取得します。
  • 住所（字地名）の判定は、取り込んだ地域データを使って端末内で行い、撮影位置は送信しません。
  • 詳細はプライバシーポリシーをご確認ください。

プライバシーポリシー: https://photogeoexplorer.pages.dev/privacy-policy
