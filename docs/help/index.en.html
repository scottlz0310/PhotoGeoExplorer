PhotoGeoExplorer Detailed Help

A guide to reviewing and organizing photo locations on a map.

Overview Requirements & Formats Getting Started Screen Layout Navigation File Operations Search & View Preview Map Places Export Multi-Select EXIF Editing Settings Logs/Updates/Support Privacy

Overview

PhotoGeoExplorer displays photo location data (EXIF/GPS) on a map to help you review and organize shooting locations.

  • Review the photo list, preview, and map in a single screen.
  • Check shooting date/time and camera info from map pins.
  • Edit EXIF data when needed (JPEG only).

Requirements & Formats

System requirements

  • Windows 10/11
  • WebView2 Runtime (for displaying detailed help)

Supported image formats

  • .jpg / .jpeg / .png / .gif / .bmp / .tif / .tiff / .heic / .webp

File associations

  • File associations are supported for .jpg / .jpeg / .png / .heic.
  • When you open an associated image, the app loads its folder automatically.

Getting Started

  • Select a folder from [File] > [Open folder...] to load photos.
  • You can also drag and drop a folder into the app.
  • Select a photo to show the preview and map on the right.
  • Map pins appear only for photos that contain location data.
  • The last opened folder is restored on startup (if missing, the closest parent folder is used).

Screen Layout

  • Left File Browser: navigate folders, search, and view items.
  • Right Top Preview: inspect the selected photo.
  • Right Bottom Map: view and interact with location pins.
  • Bottom Status Bar: item counts, selection, and GPS status.
  • Optional Places: a tree that groups the photos of the current folder by the town name where they were taken (not shown by default; see Places).

Browsing by Town Name

  • Under Layout in Settings, set the view of any region to Places to show a tree that groups the photos of the current folder by city and town (only three views fit at once, so swap it with the preview or the map).
  • Selecting a node selects the matching photos in the file list, and the map and preview follow that selection. Files and folders are never moved or changed.
  • "Water (no address)" is for places without an address such as the sea or lakes, "No area data" is for photos that have a location but no town name could be determined (a prefecture whose data is not imported, outside Japan, and so on), and "No location" is for photos without GPS.
  • To determine town names, import the area data of the prefectures under Area data (town names) in Settings (see Settings). Importing or deleting the data updates the tree automatically.
  • The locations of the photos have to be read, so a folder with many photos takes a while. Progress is shown while it runs, and Cancel stops it. Nothing is looked up while the Places pane is not shown.
  • Only the photos of the current folder shown in the file list are included (subfolders are not).

Navigation

  • Use Back/Forward to move through recent folder history.
  • Use Up and Home for quick navigation.
  • Click the breadcrumb separator ">" to open child levels.

File Operations

  • Create new folders, rename, move, and delete items.
  • Drag and drop files or folders to move them.
  • Double-click a folder to open it.

Search & View

  • Filter by file name using the search box.
  • Use Filters or View > Show images only to narrow results.
  • Change view mode (Icon/List/Details) from the View menu.
  • Details view shows extra information on hover.

Preview

  • Use the preview buttons to zoom, fit, or maximize.
  • Use previous/next to move between photos.
  • When maximized, the map area is adjusted automatically.

Map

  • Drag to pan and use the mouse wheel to zoom.
  • Click pins to view shooting time, camera, file name, and resolution.
  • Clicking a pin selects the corresponding photo in the list.
  • Open the location in Google Maps from the pin details.
  • Switch map tiles between OpenStreetMap, Esri WorldImagery (satellite imagery), Mapbox Satellite (satellite imagery), OpenFreeMap (vector map), Esri World Imagery + road names, and Mapbox Satellite + road names. OpenStreetMap is the default.
  • The "+ road names" backgrounds lay only road lines, road names, and national and prefectural route numbers over the satellite imagery. The road data comes from OpenFreeMap (OpenStreetMap). Tunnels are dashed, and footways and stairs are not shown. When the road data cannot be fetched, only the imagery is shown. Saved map images combine both (saving fails when the roads cannot be fetched).
  • Turn on "Map sources for Japan (GSI tiles)" in Settings to choose the Standard Map, Pale Map, Aerial Imagery, or Vector Map. The setting defaults to on for the Japanese UI. Turning it off while a GSI map is selected switches to OpenStreetMap. Areas outside the source coverage may appear blank.
  • OpenStreetMap, Esri, OpenFreeMap, and GSI tiles are cached locally for faster reloading. Mapbox tiles are not stored on the device.
  • Mapbox Satellite requires a public access token (starting with pk.) issued from your own Mapbox account. Enter it under Map in Settings and choose Save to enable the option. Use Test connection to check that the token works.
  • The token is stored in Windows Credential Manager and is never written to the settings file or exports. Secret tokens (sk.) cannot be saved.
  • Mapbox usage and charges are billed to the account that issued the token. See the Mapbox pricing page (Raster Tiles API) for the free tier and rates. URL-restricted tokens may not work from a desktop app.
  • If Mapbox Satellite (including "Mapbox Satellite + road names") is selected but no token is set, OpenStreetMap is shown and a notice appears at the top left of the map.
  • OpenFreeMap (vector map) draws the whole displayed area as a single image from map data. When you first display it or move far away, it takes a moment to fetch the data and draw, and the previous map is scaled in the meantime, so the outer area can be blank. When the network is unavailable, the parts that could not be fetched are left blank.
  • With OpenFreeMap (vector map), when your operation stops, map data near the center of the displayed area is fetched in advance to make the next zoom-out faster.
  • The map provider attribution is shown at the bottom right of the map. While Mapbox imagery is displayed, the Mapbox logo is also shown at the bottom left. The "+ road names" backgrounds show the imagery and road data providers on two lines. Both are included in saved map images.
  • The save button in the map header opens the save map image dialog. Choose the background (initially the displayed one; the backgrounds available in Settings, with the Mapbox backgrounds only when an access token is set), size (current view, 1280 × 720, 1600 × 1200, or custom; 64 to 4096 px per side), zoom, and text size, check the preview, and choose "Save..." to save a PNG. "Save..." is available once the preview for the current settings is shown. If the preview cannot be created, choose "Retry". Changing these does not change the main map. With a larger text size, "Current view" keeps the same area in a larger image, while a fixed size shows a smaller area. Each preview fetches the map tiles it needs (up to 256 per image).
  • When you select a single photo, the address (town name), the nearest road name (a suggestion), and the latitude/longitude of its location are shown to the right of the map title. Click the latitude/longitude to copy it. Choose the items to show from the right-click menu of the header or under Map in Settings.
  • The address appears once you import the data for the prefecture under Area data (town names) in Settings (see Settings below). Point at the address to see the small-area code and the census year. When the photo location is outside every small-area boundary, the nearest area within 30 m is shown and the tooltip says so. No address is shown over water such as the sea or lakes.
  • The nearest road name (a suggestion) is found by looking up to 3 roads within 50 m of the photo location, nearest first; the name of the nearest one is shown ("(+1)" is the number of other candidates). Click the road name to open the list of candidates (name, route number, distance); point at it to see the distance. The nearest road is not necessarily the road that was photographed, so it is a suggestion, not a fact. The type of road (national route, prefectural road, and so on) is never guessed: a national route is shown by its name (such as "国道53号"), and a road without a name is shown as "Route 203". Footpaths such as station platforms are not included.
  • Press "Confirm" in the list of road candidates to confirm one as that photo's road name (a confirmed photo shows "✓ road name"; "Clear" in the list undoes it). The confirmation is not written to the photo file; it is saved on your device at %LocalAppData%\PhotoGeoExplorer\road-name-confirmations.json and is never sent anywhere. Moving or renaming a photo removes its confirmation.
  • To find the nearest road name, road tiles are fetched from OpenFreeMap. Only the tile number (about 2 km square) is sent; the photo and its latitude/longitude themselves are not. If you do not want this connection, turn off "Show nearest road name (suggestion)" under Map in Settings (see the Privacy Policy). Fetched tiles are cached on your device; offline, only cached tiles are used.

Export (with Location Data)

  • Select photos in the file list, then use File > Export or Export in the right-click menu of the file list. The original photos are never changed. Selecting a node in the Places pane selects the photos of that place, so you can export them right away.
  • List with locations (CSV): saves the file name, prefecture, city, town, key code, latitude, longitude, date taken, status, road name, and road name status as a CSV (UTF-8 with BOM) that Excel opens as it is. The road name status is Confirmed (the road name you confirmed in the list of road candidates), Candidate (the first nearest-road candidate of a photo that is not confirmed), or None; the new columns are added at the end, so the positions of the existing columns do not change. For photos without a town name, the address columns are blank and the status says No area data, No location, or Water.
  • Copy to town-name folders: creates city > town folders under the destination and copies the photos into them. Photos without a town name go to the Water (no address), No area data, and No location folders.
  • Copy with date, town and road names: copies the photos to the destination with names such as "20240102_Higashi-hinjicho_Yamanote-dori_001.jpg" (date taken, town name, road name, sequence number). Only a confirmed road name is used; photos that are not confirmed get "No road name" (a candidate cannot be told apart from a confirmed value, so it is not put in the file name).
  • Road name candidates are fetched from OpenFreeMap (road tiles) at export time only while "Show nearest road name (suggestion)" under Settings is on (the same setting and connection as the map header). When it is off, nothing is sent and only confirmed road names are written. The road name of a photo that could not be fetched is left empty, and the completion message says so.
  • When a file with the same name already exists at the destination, you can choose Overwrite, Skip, or Cancel (or Overwrite all / Skip all).
  • While exporting, the progress is shown in the status bar and Cancel stops it. When it ends, the numbers of copied, skipped, and failed photos are shown.
  • To determine town names, import the area data of the prefectures under Area data (town names) in Settings (photos of prefectures that are not imported are put in No area data).

Multi-Select & Rectangle Selection

  • Use Ctrl/Shift for multi-selection.
  • Hold Ctrl and drag on the map to create a selection rectangle.
  • Photos inside the rectangle are selected and reflected in the list.

EXIF Editing

  • Right-click a photo and choose Edit EXIF (JPEG only).
  • Edit shooting date/time, latitude, and longitude.
  • Use "Get location from map" to pick a location by clicking the map.
  • Right-click cancels location selection.

Settings

  • Switch language and theme (restart required after change).
  • Change the default map zoom level and tile source.
  • Under Layout, choose the view of each region (File, Preview, Map, Places).
  • Export and import settings.
  • Under Area data (town names), import or delete the data used to determine the address shown in the map header (see below).

Importing area data (town names)

  1. On the boundary data download page of e-Stat (Portal Site of Official Statistics of Japan), choose Census, small area (town/block), 2020, JGD2011 latitude/longitude, Shape format, and download the ZIP of each prefecture you want.
  2. Under Area data (town names) in Settings, choose Add ZIP... and select the downloaded ZIP. Data for the same prefecture is replaced.
  3. Choose Delete in the list to remove data you no longer need.

Downloading area data (town names)

  • When you select a photo in an area that has no area data, a dialog asks whether to download it. If you choose Download, the app downloads the data of that prefecture from e-Stat (Portal Site of Official Statistics of Japan) and imports it. While it downloads, the amount received is shown at the bottom left of the map. Choose Cancel to stop.
  • If you check "Download without asking from now on" in the dialog, the app downloads without asking from then on. If you choose "Never download", the app neither asks nor downloads from then on. You can change this at any time with "When I select a photo in an area with no data" under Area data (town names) in Settings: "Ask whether to download" (default), "Download without asking", or "Do nothing". Even with "Do nothing", you can still download from Settings or import a ZIP.
  • You can also choose a prefecture under Area data (town names) in Settings and select Download from e-Stat.
  • The size of the data is not known until it is downloaded. If the download fails, you can import the ZIP manually as described above.
  • Your photos and their locations are not sent. The app only connects to the URL of the prefecture data (your IP address and the app name reach the server as ordinary connection information).

Imported data is stored at %LocalAppData%\PhotoGeoExplorer\AreaData, and the address lookup runs on this device.

Source: Portal Site of Official Statistics of Japan (e-Stat) (https://www.e-stat.go.jp/), "Census small area (town/block) boundary data" (Statistics Bureau, Ministry of Internal Affairs and Communications), processed by this app. This data was not created by the national government or the Ministry.

Logs/Updates/Support

Logs

  • Open logs from Help > Open Log Folder.
  • Log location: %LocalAppData%\PhotoGeoExplorer\Logs\app.log

Updates

  • Check updates via Help > Check for updates (GitHub Releases).

Support

  • Report issues on GitHub Issues.
  • Include repro steps and logs when possible.

Privacy

  • Photos and settings are processed locally and not uploaded.
  • Map tiles are fetched from OpenStreetMap and Esri servers. When OpenFreeMap (vector map) is selected, they are fetched from OpenFreeMap servers, and when Mapbox Satellite is selected, from Mapbox servers. GSI tiles are fetched from Geospatial Information Authority of Japan servers when selected. The "+ road names" backgrounds fetch from both the imagery provider (Esri or Mapbox) and OpenFreeMap.
  • The address lookup uses the area data you imported, runs on this device, and does not send the photo location.
  • See the privacy policy for details.

Privacy policy: https://photogeoexplorer.pages.dev/privacy-policy
