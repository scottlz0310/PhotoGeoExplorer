PhotoGeoExplorer Detailed Help

A guide to reviewing and organizing photo locations on a map.

Overview Requirements & Formats Getting Started Screen Layout Navigation File Operations Search & View Preview Map Places Multi-Select EXIF Editing Settings Logs/Updates/Support Privacy

Overview

PhotoGeoExplorer displays photo location data (EXIF/GPS) on a map to help you review and organize shooting locations.

  • Review the photo list, preview, and map in a single screen.
  • Check shooting date/time and camera info from map pins.
  • Edit EXIF data when needed (JPEG only).

Requirements & Formats

System requirements

  • Windows 10/11
  • WebView2 Runtime (for displaying detailed help)

Supported image formats

  • .jpg / .jpeg / .png / .gif / .bmp / .tif / .tiff / .heic / .webp

File associations

  • File associations are supported for .jpg / .jpeg / .png / .heic.
  • When you open an associated image, the app loads its folder automatically.

Getting Started

  • Select a folder from [File] > [Open folder...] to load photos.
  • You can also drag and drop a folder into the app.
  • Select a photo to show the preview and map on the right.
  • Map pins appear only for photos that contain location data.
  • The last opened folder is restored on startup (if missing, the closest parent folder is used).

Screen Layout

  • Left File Browser: navigate folders, search, and view items.
  • Right Top Preview: inspect the selected photo.
  • Right Bottom Map: view and interact with location pins.
  • Bottom Status Bar: item counts, selection, and GPS status.
  • Optional Places: a tree that groups the photos of the current folder by the town name where they were taken (not shown by default; see Places).

Browsing by Town Name

  • Under Layout in Settings, set the view of any region to Places to show a tree that groups the photos of the current folder by city and town (only three views fit at once, so swap it with the preview or the map).
  • Selecting a node selects the matching photos in the file list, and the map and preview follow that selection. Files and folders are never moved or changed.
  • "Water (no address)" is for places without an address such as the sea or lakes, "No area data" is for photos that have a location but no town name could be determined (a prefecture whose data is not imported, outside Japan, and so on), and "No location" is for photos without GPS.
  • To determine town names, import the area data of the prefectures under Area data (town names) in Settings (see Settings). Importing or deleting the data updates the tree automatically.
  • The locations of the photos have to be read, so a folder with many photos takes a while. Progress is shown while it runs, and Cancel stops it. Nothing is looked up while the Places pane is not shown.
  • Only the photos of the current folder shown in the file list are included (subfolders are not).

Navigation

  • Use Back/Forward to move through recent folder history.
  • Use Up and Home for quick navigation.
  • Click the breadcrumb separator ">" to open child levels.

File Operations

  • Create new folders, rename, move, and delete items.
  • Drag and drop files or folders to move them.
  • Double-click a folder to open it.

Search & View

  • Filter by file name using the search box.
  • Use Filters or View > Show images only to narrow results.
  • Change view mode (Icon/List/Details) from the View menu.
  • Details view shows extra information on hover.

Preview

  • Use the preview buttons to zoom, fit, or maximize.
  • Use previous/next to move between photos.
  • When maximized, the map area is adjusted automatically.

Map

  • Drag to pan and use the mouse wheel to zoom.
  • Click pins to view shooting time, camera, file name, and resolution.
  • Clicking a pin selects the corresponding photo in the list.
  • Open the location in Google Maps from the pin details.
  • Switch map tiles between OpenStreetMap, Esri WorldImagery (satellite imagery), and Mapbox Satellite (satellite imagery).
  • OpenStreetMap and Esri tiles are cached locally for faster reloading. Mapbox tiles are not stored on the device.
  • Mapbox Satellite requires a public access token (starting with pk.) issued from your own Mapbox account. Enter it under Map in Settings and choose Save to enable the option. Use Test connection to check that the token works.
  • The token is stored in Windows Credential Manager and is never written to the settings file or exports. Secret tokens (sk.) cannot be saved.
  • Mapbox usage and charges are billed to the account that issued the token. See the Mapbox pricing page (Raster Tiles API) for the free tier and rates. URL-restricted tokens may not work from a desktop app.
  • If Mapbox Satellite is selected but no token is set, OpenStreetMap is shown and a notice appears at the top left of the map.
  • The map provider attribution is shown at the bottom right of the map. While Mapbox Satellite is displayed, the Mapbox logo is also shown at the bottom left. Both are included in saved map images.
  • When you select a single photo, the address (town name) and the latitude/longitude of its location are shown to the right of the map title. Click the latitude/longitude to copy it. Choose the items to show from the right-click menu of the header or under Map in Settings.
  • The address appears once you import the data for the prefecture under Area data (town names) in Settings (see Settings below). Point at the address to see the small-area code and the census year. When the photo location is outside every small-area boundary, the nearest area within 30 m is shown and the tooltip says so. No address is shown over water such as the sea or lakes.

Multi-Select & Rectangle Selection

  • Use Ctrl/Shift for multi-selection.
  • Hold Ctrl and drag on the map to create a selection rectangle.
  • Photos inside the rectangle are selected and reflected in the list.

EXIF Editing

  • Right-click a photo and choose Edit EXIF (JPEG only).
  • Edit shooting date/time, latitude, and longitude.
  • Use "Get location from map" to pick a location by clicking the map.
  • Right-click cancels location selection.

Settings

  • Switch language and theme (restart required after change).
  • Change the default map zoom level and tile source.
  • Under Layout, choose the view of each region (File, Preview, Map, Places).
  • Export and import settings.
  • Under Area data (town names), import or delete the data used to determine the address shown in the map header (see below).

Importing area data (town names)

  1. On the boundary data download page of e-Stat (Portal Site of Official Statistics of Japan), choose Census, small area (town/block), 2020, JGD2011 latitude/longitude, Shape format, and download the ZIP of each prefecture you want.
  2. Under Area data (town names) in Settings, choose Add ZIP... and select the downloaded ZIP. Data for the same prefecture is replaced.
  3. Choose Delete in the list to remove data you no longer need.

Imported data is stored at %LocalAppData%\PhotoGeoExplorer\AreaData, and the address lookup runs on this device. The app does not download this data itself.

Source: Portal Site of Official Statistics of Japan (e-Stat) (https://www.e-stat.go.jp/), "Census small area (town/block) boundary data" (Statistics Bureau, Ministry of Internal Affairs and Communications), processed by this app. This data was not created by the national government or the Ministry.

Logs/Updates/Support

Logs

  • Open logs from Help > Open Log Folder.
  • Log location: %LocalAppData%\PhotoGeoExplorer\Logs\app.log

Updates

  • Check updates via Help > Check for updates (GitHub Releases).

Support

  • Report issues on GitHub Issues.
  • Include repro steps and logs when possible.

Privacy

  • Photos and settings are processed locally and not uploaded.
  • Map tiles are fetched from OpenStreetMap and Esri servers. When Mapbox Satellite is selected, tiles are fetched from Mapbox servers.
  • The address lookup uses the area data you imported, runs on this device, and does not send the photo location.
  • See the privacy policy for details.
