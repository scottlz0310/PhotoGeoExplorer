要約: PhotoGeoExplorer はプライバシーを重視したデスクトップアプリです。データは端末内で処理され、個人情報を収集・保存・共有しません。

1. はじめに

PhotoGeoExplorer（以下「本アプリ」）は、写真の位置情報を地図上で表示・探索する Windows デスクトップアプリです。本ポリシーでは、本アプリがどのようにデータを取り扱い、プライバシーを保護するかを説明します。

2. 収集しない情報

本アプリはプライバシーを重視して設計されています。本アプリは次のことを行いません。

  • 個人情報の収集
  • 利用状況や行動のトラッキング
  • アカウント登録・ログインの要求
  • 写真やデータのサーバーへのアップロード
  • 第三者への個人情報の共有

3. 端末内でのデータ処理

本アプリのデータ処理は、すべてお使いの端末内で完結します。

  • 写真ファイル: 本アプリは、あなたが明示的に選択したフォルダー内の写真のみを読み取ります。写真は端末内に留まり、アップロードされません。
  • EXIF メタデータ: 位置情報表示のために、写真内の EXIF/GPS データを読み取ります。処理は端末内で行われ、外部へ送信されません。
  • 設定: 言語・テーマなどの設定は、端末内の %LocalAppData%\PhotoGeoExplorer\settings.json に保存されます。
  • ログ: トラブルシュート目的で、端末内の %LocalAppData%\PhotoGeoExplorer\Logs\app.log にアプリログが保存されます。
  • 地図タイルキャッシュ: 地図表示のために取得したタイルは、性能向上と通信量削減のため %LocalAppData%\PhotoGeoExplorer\Cache\Tiles にキャッシュされます（Mapbox のタイルは端末に保存しません）。
  • Mapbox アクセストークン: Mapbox Satellite を使うために利用者が入力したアクセストークンは、Windows の資格情報マネージャーに保存されます。設定ファイル・ログ・クラッシュレポートには記録しません。
  • 地域データ（字地名）: 地図ヘッダーに住所（字地名）を表示するために、利用者が選んだ ZIP （e-Stat の国勢調査 小地域境界データ）を読み取り、端末内の %LocalAppData%\PhotoGeoExplorer\AreaData に保存します。住所の判定は端末内で行い、撮影位置は外部へ送信されません。設定から削除できます。
  • 確定した道路名: 地図ヘッダーの候補の一覧で利用者が確定した道路名は、写真のパス・ファイルサイズ・撮影日時とともに、端末内の %LocalAppData%\PhotoGeoExplorer\road-name-confirmations.json に保存されます。写真のファイルには書き込まず、外部へは送信しません。
  • 道路のタイルキャッシュ: 地図ヘッダーに最寄りの道路名（候補）を表示するために取得した道路のタイルは、端末内の %LocalAppData%\PhotoGeoExplorer\Cache\RoadTiles にキャッシュされます（最大約 200 MB）。道路名の判定は端末内で行います。

4. インターネット通信

本アプリは、次の目的に限って最小限のインターネット通信を行います。

  • 地図タイル: 地図表示のため、OpenStreetMap または Esri WorldImagery のサーバーから地図タイルを取得します。これらのリクエストに個人情報は含めません。
  • Mapbox Satellite（任意）: 利用者が自分のアクセストークンを設定して Mapbox Satellite を選んだ場合に限り、Mapbox のサーバーから地図タイルを取得します。リクエストには、表示範囲のタイル座標と利用者のアクセストークンが含まれます。写真データは送信しません。
  • 最寄り道路名（既定で有効。オフにできます）: 地図ヘッダーに最寄りの道路名（候補）を表示するために、OpenFreeMap のサーバーから道路のタイルを取得します。リクエストに含まれるのは、撮影地点を含むタイルの番号（ズーム 14。約 2 km 四方で、地点が縁に近いときは隣のタイルも）と、本アプリの名称・版・連絡先（User-Agent）です。写真や緯度経度そのものは送信しませんが、タイルの番号から、撮影地点を含む約 2 km 四方の範囲は分かります。設定の「最寄り道路名（候補）を表示」をオフにすると、この通信は行いません。位置情報つきの書き出し（CSV・リネームしてコピー）で、未確定の写真の道路名の候補を求めるときも、同じ設定がオンのときだけ、同じ内容（タイルの番号と User-Agent）を送ります。
  • 更新チェック: 新バージョン確認のため、GitHub Releases を参照します。これらのリクエストに個人情報や写真データは含めません。

地域データ（字地名）は、本アプリが通信して取得することはありません。e-Stat からのダウンロードは、利用者がブラウザーで行います。

初回の地図タイルがキャッシュされた後は、オフラインでも利用できます（地図の新規取得は除く）。最寄り道路名は、オフラインではキャッシュにあるタイルだけで判定し、なければ表示しません。

5. 第三者サービス

本アプリは次の第三者サービスを利用しますが、個人情報を共有しません。

  • OpenStreetMap: 地図タイルを OpenStreetMap のタイルサーバーから取得します。詳しくは Privacy Policy を参照してください。
  • OpenFreeMap（最寄り道路名）: 道路のタイルを OpenFreeMap のサーバーから取得します。地図データは OpenStreetMap の貢献者によるものです。
  • Esri WorldImagery: 衛星画像タイルを Esri のサーバーから取得します。詳しくは Privacy Policy を参照してください。
  • Mapbox（任意）: 利用者がアクセストークンを設定した場合に、衛星画像タイルを Mapbox のサーバーから取得します。詳しくは Privacy Policy を参照してください。
  • GitHub: 更新チェックは GitHub API 経由で行われます。詳しくは GitHub Privacy Statement を参照してください。

6. Google Maps 連携

本アプリには、写真の位置をブラウザーで Google Maps を開く任意機能があります。「Google Maps で開く」をクリックした場合、緯度・経度がブラウザーの Google Maps に渡されます。この操作はあなたが明示的に行う場合にのみ実行されます。詳しくは Google のプライバシーポリシー を参照してください。

7. データの安全性

データは端末内に保存されるため、端末のセキュリティ管理は基本的にユーザーの責任となります。

  • Windows とセキュリティソフトを最新の状態に保つ
  • 写真フォルダーのアクセス権限を適切に管理する
  • 重要な写真は定期的にバックアップする

8. 子どものプライバシー

本アプリは、子どもから個人情報を意図的に収集することはありません。本アプリは一般向けであり、アカウント登録等も不要です。

9. 本ポリシーの変更

本ポリシーは必要に応じて更新される場合があります。変更がある場合は本ページに掲載し、「最終更新日」を更新します。変更後に本アプリを継続して利用することで、更新後の内容に同意したものとみなされます。

Summary: PhotoGeoExplorer is a privacy-focused desktop app. Your data is processed locally and no personal information is collected, stored, or shared.

1. Introduction

PhotoGeoExplorer (the "App") is a Windows desktop application that displays and explores photo location information on a map. This policy explains how the App handles data and protects your privacy.

2. Information We Do Not Collect

The App is designed with privacy in mind. We do not:

  • Collect personal information
  • Track usage or behavior
  • Require account creation or sign-in
  • Upload photos or data to a server
  • Share personal information with third parties

3. Local Data Processing

All data processing is performed locally on your device.

  • Photo files: The App reads only photos in folders you explicitly select. Photos remain on your device and are never uploaded.
  • EXIF metadata: EXIF/GPS data is read to display locations. Processing is local and not transmitted externally.
  • Settings: Language/theme settings are stored at %LocalAppData%\PhotoGeoExplorer\settings.json.
  • Logs: For troubleshooting, logs are stored at %LocalAppData%\PhotoGeoExplorer\Logs\app.log.
  • Map tile cache: Tiles are cached at %LocalAppData%\PhotoGeoExplorer\Cache\Tiles to improve performance and reduce network traffic (Mapbox tiles are not stored on the device).
  • Mapbox access token: The access token you enter to use Mapbox Satellite is stored in Windows Credential Manager. It is not written to the settings file, logs, or crash reports.
  • Area data (town names): To show the address (town name) in the map header, the App reads the ZIP you select (e-Stat census small-area boundary data) and stores it at %LocalAppData%\PhotoGeoExplorer\AreaData on your device. The address lookup is done locally and the photo location is not sent externally. You can delete the data from Settings.
  • Confirmed road names: A road name you confirm in the list of candidates in the map header is saved on your device at %LocalAppData%\PhotoGeoExplorer\road-name-confirmations.json, together with the photo's path, file size, and taken-at time. It is not written to the photo file and is never sent anywhere.
  • Road tile cache: Road tiles fetched to show the nearest road name (a suggestion) in the map header are cached at %LocalAppData%\PhotoGeoExplorer\Cache\RoadTiles (up to about 200 MB). Road names are determined on your device.

4. Network Communication

The App performs minimal network access only for the purposes below:

  • Map tiles: Map tiles are fetched from OpenStreetMap or Esri WorldImagery servers. These requests do not include personal information.
  • Mapbox Satellite (optional): Only when you set your own access token and select Mapbox Satellite, map tiles are fetched from Mapbox servers. These requests include the tile coordinates of the displayed area and your access token. Photo data is not sent.
  • Nearest road name (enabled by default; can be turned off): To show the nearest road name (a suggestion) in the map header, road tiles are fetched from OpenFreeMap servers. A request contains only the number of the tile that contains the photo location (a zoom-14 tile, about 2 km square; adjacent tiles when the location is near the edge) and the App's name, version, and contact address (User-Agent). Photos and the latitude and longitude themselves are not sent, but the tile number reveals the area of about 2 km square around the photo location. Turn off "Show nearest road name (suggestion)" in Settings to stop these requests. When you export photos with location data (CSV, or copy with new names), the same requests are made, with the same content (tile numbers and User-Agent), only while that setting is on, to find the candidates for photos whose road name is not confirmed.
  • Update checks: GitHub Releases are queried for new versions. These requests do not include personal information or photo data.

The App never downloads area data (town names) itself. You download it from e-Stat in your browser.

Once map tiles are cached, the App can be used offline (except for fetching new tiles). Offline, the nearest road name is determined only from cached tiles; if the tiles are not cached, it is not shown.

5. Third-Party Services

The App uses the following services without sharing personal information:

  • OpenStreetMap: Map tiles are fetched from OpenStreetMap. See their Privacy Policy.
  • OpenFreeMap (nearest road name): Road tiles are fetched from OpenFreeMap. The map data is by OpenStreetMap contributors.
  • Esri WorldImagery: Satellite tiles are fetched from Esri. See their Privacy Policy.
  • Mapbox (optional): When you set an access token, satellite tiles are fetched from Mapbox. See their Privacy Policy.
  • GitHub: Update checks use GitHub APIs. See the GitHub Privacy Statement.

6. Google Maps Integration

The App includes an optional feature to open photo locations in Google Maps. When you click "Open in Google Maps", latitude and longitude are passed to Google Maps in your browser. This occurs only when you explicitly choose to do so. See Google's Privacy Policy.

7. Data Security

Because all data is stored locally, device security is the user's responsibility.

  • Keep Windows and security software up to date
  • Manage access permissions for your photo folders
  • Back up important photos regularly

8. Children's Privacy

The App does not knowingly collect personal information from children. It is intended for general audiences and does not require accounts.
