# 同梱データ

## prefecture-polygons.tsv

写真の座標から、字地名の判定に使う都道府県（候補）を絞り込むための、簡略化した都道府県ポリゴンです。`PrefectureLocator` が読みます。

### 出典

- 出典: 政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）
- 「令和 2 年国勢調査 小地域（町丁・字等別）境界データ」（総務省統計局）を加工して作成
- 取得日: 2026-11-13（全国 47 都道府県。世界測地系 緯度経度・JGD2011、Shapefile）

e-Stat 利用規約（政府標準利用規約 第 2.0 版に準拠。CC BY 4.0 と互換）に従い、出典と、加工して作成したことを記載しています。このデータは国・総務省が作成したものではありません。

### 形式

- 1 行に 1 都道府県。「都道府県コード（2 桁）」「タブ」「WKT（`POLYGON` または `MULTIPOLYGON`）」
- 座標は「経度 緯度」の順、小数 5 桁まで
- `#` で始まる行はコメント

### 加工の内容

都道府県ごとに、次の順で加工しています（値は `scripts/Build-PrefecturePolygons.cs` の定数）。

1. 小地域のポリゴン（陸・水面の両方）を、それぞれ 0.0002 度で簡略化してから融合する
2. 外側へ 0.01 度（南北に約 1.1km）膨らませる
3. 0.004 度で簡略化し、穴を取り除く

膨らませる幅を簡略化のずれの合計より大きくしてあるので、**加工後のポリゴンは元の小地域をすべて覆います**（スクリプトが検査し、覆えていなければ失敗します）。そのため、県境からおよそ 1km 以内の地点は、隣接する都道府県の両方が候補になります。どちらの都道府県かは、小地域のポリゴンへの内包判定で確定します。

### 作り直す手順

国勢調査の年次が変わったときなどに作り直します。

1. e-Stat の統計地理情報システム（境界データダウンロード）から、国勢調査の「小地域（町丁・字等別）」の「世界測地系緯度経度・Shapefile」を 47 都道府県分取得し、`r2ka01.zip` 〜 `r2ka47.zip` の名前で 1 つのフォルダーに置く。令和 2 年分は、次の URL の `<コード>` を `01`〜`47` に替えて取得した

   ```text
   https://www.e-stat.go.jp/gis/statmap-search/data?dlserveyId=A002005212020&code=<コード>&coordSys=1&format=shape&downloadType=5&datum=2011
   ```

2. リポジトリのルートで実行する（開発機で 6〜7 分）

   ```powershell
   dotnet run scripts/Build-PrefecturePolygons.cs -- <ZIP のフォルダー> PhotoGeoExplorer.Core/Resources/prefecture-polygons.tsv
   ```

3. `dotnet test` で `PrefectureLocatorTests` が通ることを確認する
4. 年次を変えた場合は、この文書の出典と取得日を更新する
