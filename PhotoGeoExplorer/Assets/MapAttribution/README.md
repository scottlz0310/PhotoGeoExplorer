# 地図の帰属表示用アセット

## mapbox-logo.svg

Mapbox の背景地図（Mapbox Satellite）を表示するときに、地図の左下へ描くロゴです。Mapbox は、Mapbox のタイルセットを使う地図にロゴと文言の両方の帰属表示を求めています。

- 出所: Mapbox 公式ドキュメント「Attribution」（<https://docs.mapbox.com/help/dive-deeper/attribution/>）の、帰属表示用スタイル（`.mapbox-logo`）に埋め込まれている SVG を、加工せずに取り出したもの（取得日: 2026-11-12）
- 権利: ロゴは Mapbox の専有物であり、本リポジトリのライセンス（MIT License）の対象外です。帰属表示の目的でだけ使います
- 加工の禁止: Mapbox はロゴの加工（色の変更、変形、影など）を認めていません。差し替えるときも、公式の素材を加工せずに使ってください
- 表示サイズ: 公式の帰属表示コントロールと同じ 88×23（`MapAttributionPresenter`）

再配布の可否は、Mapbox の公開ページでは明示されていません。Mapbox から求めがあった場合は、同梱をやめて別の取得方法へ切り替えます。
